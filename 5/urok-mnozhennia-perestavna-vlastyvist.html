Актуалізація

Відповідь:

Множення. Множники й добуток

1=
Добутком числа a на натуральне число b, яке не дорівнює 1, називають суму, що складається з b доданків, кожний з яких дорівнює a. a · b = a + a + … + ab доданків
У рівності a · b = c числа a і b називають множниками, а число c і запис a · b — добутком.

Додаткове завдання

Множники 1 і 0

Домовились, що a · 1 = a.
Домовилися вважати, що a · 0 = 0. Зокрема, 0 · 0 = 0.

Нехай a =

Якщо один із двох множників дорівнює 1, то добуток дорівнює другому множнику:a · 1 = 1 · a = a
Якщо один із множників дорівнює нулю, то добуток дорівнює нулю:a · 0 = 0 · a = 0
Добуток двох чисел, відмінних від нуля, нулем бути не може.
Якщо добуток дорівнює нулю, то хоча б один із множників дорівнює нулю.

# matemka
Інтерактивні розробки з математики для сайту Матемка

## Контрольна й Моніторинг за Блумом

- `bloom/index.html` — Контрольна за Блумом (TGI-шкала, 100 балів, результати в колекції `results_bloom_control`). У журналі 🔑 відсоток за кожним рівнем Блума позначено кольором рівня сформованості (90 / 74 / 60 %).
- `monitoring/index.html` — Моніторинг за Блумом (колекція `results_bloom_monitoring`), побудований за документом «Моніторинг якості знань за таксономією Блума»:
  - повний зріз — 10 завдань, 24 бали, по 4 бали на кожен рівень; компонент К1 (наскрізний) і К2 (змістовий); якірні завдання («розуміння» К1 та «оцінювання») однакові в усіх зрізах для одного учня;
  - «оцінювання» і «створення» перевіряє вчитель за універсальною рубрикою 0–4;
  - вхідний, проміжний (лише К1, грудень) і підсумковий зрізи; змістові теми (К2) вибирають окремо для кожного зрізу;
  - звіт: медіани, Δ, індекс g (Хейка), рівні сформованості, матриця переходів, перевірка якірних, правила «дані → рішення», S(TGI), два CSV.
